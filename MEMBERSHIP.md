# Вступление в Russian Creators Web Ring

Russian Creators Web Ring объединяет независимые сайты, которые создаются и развиваются на русском языке. Это языковое и творческое сообщество: оно не связано с гражданством, национальностью, государством или политической позицией автора.

## Что подходит

- самостоятельный сайт, блог, портфолио, веб-проект или творческая страница с устойчивым авторским содержанием на русском;
- сайт, доступный без обязательной регистрации;
- сайт, на который можно поставить две ссылки кольца.

Не включаются страницы с политической агитацией, травлей, дискриминацией, незаконным содержимым, рекламные лендинги без содержательной части и сайты, не поддерживающие ссылки кольца. Модерация может отказать или исключить сайт с кратким объяснением.

## Заявка

Создайте issue через форму в репозитории. Укажите название сайта и URL, короткое описание, имя или псевдоним автора, RSS/Atom-адрес (если есть) и желаемый `slug` из строчных латинских букв, цифр и дефисов.

Перед включением установите навигационный блок. После одобрения замените `your-slug` на согласованный slug:

```html
<nav aria-label="Russian Creators Web Ring">
  <a href="https://dionisiubrovka.github.io/russian-creators-webring/your-slug/previous/">← Предыдущий</a>
  <a href="https://dionisiubrovka.github.io/russian-creators-webring/your-slug/next/">Следующий →</a>
</nav>
```

## Как поддерживается реестр

Реестр находится в `websites.json`. Для каждого принятого сайта добавляется объект по образцу `websites.example.json`, затем сайт пересобирается. Проверка `cargo run --release -- --audit` дополнительно убеждается, что обе ссылки установлены; включайте её после появления первых участников.
