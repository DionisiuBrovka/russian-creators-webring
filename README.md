# Russian Creators Web Ring

Веб-кольцо независимых сайтов, которые создаются и развиваются на русском языке. Это сообщество языка и творчества, а не государств, национальностей или политических взглядов.

Каждый участник размещает ссылки на предыдущий и следующий сайты кольца, а также ссылку на главную страницу RCWR. Так сайты соединяются в маршрут, по которому можно открывать новые авторские проекты без алгоритмов рекомендаций, рейтингов, лайков или платного продвижения.

Главная страница публикуется по адресу: <https://dionisiubrovka.github.io/russian-creators-webring/>.

## Для участников

Вступить может самостоятельный сайт с заметным авторским содержанием на русском языке. Подробные правила, принципы, требования и код навигационного блока с тремя ссылками находятся в [MEMBERSHIP.md](MEMBERSHIP.md). Заявку можно подать через [Issues](https://github.com/DionisiuBrovka/russian-creators-webring/issues/new/choose).

## Как обновить кольцо

1. Добавьте или обновите запись в `websites.json`, ориентируясь на `websites.example.json`.
2. Локально проверьте и соберите сайт:

   ```bash
   cargo run --release --
   ```

   Результат находится в игнорируемой Git папке `webring/`.
3. Откройте `webring/index.html` в браузере и проверьте ссылки.
4. Закоммитьте изменения исходников. GitHub Actions пересоберёт и опубликует сайт.

Когда участники уже установили навигационный блок, дополнительная проверка ссылок запускается так:

```bash
cargo run --release -- --audit
```

## Структура

- `ringfairy.toml` — название, описание, публичный URL и настройки сборки;
- `websites.json` — актуальный реестр;
- `data/templates/` — HTML-шаблоны;
- `data/assets/` — стили и будущие статические файлы;
- `webring/` — сгенерированный сайт, не хранится в репозитории.

Генератор основан на [ringfairy](https://github.com/k3rs3d/ringfairy) и лицензируется по GPL-3.0.
